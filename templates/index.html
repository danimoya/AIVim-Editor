def fibonacci(n):
    """Calculate the nth Fibonacci number"""
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    else:
        return fibonacci(n-1) + fibonacci(n-2)

Quick Reference

Command Description
:explain 1 10 Explain code from lines 1 to 10
:improve 1 10 Improve code from lines 1 to 10
:generate 5 "Create a function to sort a list" Generate code at line 5 based on the description
:ai "What does this code do?" Ask a custom question about the current file
